## New accessory feature foundation
- Migration: v2/supabase/migrations/003_vio_character_accessories.sql
- Table: public.vio_character_accessories
- PNG/WebP accessory metadata is separated from expression assets.
- Per-item fields: x/y position, width/height, mirror, follow_avatar, effects_enabled, sort_order.
- Storage path is scoped under the owner's app user ID.
- Owner-only RLS read/write policies.
- Edge Function actions: record_accessory, update_accessory, delete_accessory.
- my_assets returns signed accessory URLs for the active character.
- room_members and overlay_connect include signed accessory snapshots.
- OBS overlay and editor call AvatarRenderer.setAccessories().
- Renderer supports follow-avatar translation/rotation and basic global visual effects on enabled accessories.
- Admin Support View can inspect and delete accessory assets; account deletion cleans accessory storage objects.
- UI supports multi-file PNG/WebP upload and per-item position, size, mirror, follow and effects controls.

## Security hardening already in branch
- Migration 002 narrows direct cross-account Admin RLS access and requires active/unexpired rooms for Realtime read/write.
- Admin bootstrap is serialized and constrained to one Admin row.
- Edge overlay_connect rejects expired rooms.
- Disabling a target revokes active Support View sessions.
- CI has regression tests for these security requirements.
