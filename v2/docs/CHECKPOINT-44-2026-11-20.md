# Checkpoint 44 — 20 November 2026

## User-reported mobile QA requirements
Based on three Android Chrome screenshots, the user requested:
1. Microphone input toggle with explicit ON/OFF mode.
2. Attempt microphone startup immediately when entering the authenticated workspace.
3. Narrower mobile sidebar, larger navigation icons, and a protruding mid-edge expand/collapse tab showing `>` / `<` rather than a hamburger glyph.
4. Smaller avatar preview viewport so settings below the stage are discoverable without excessive scrolling.
5. Reliable OBS link generation from Home and Collaboration, loading feedback, a success popup/toast after creation, then a `Salin Link` button that copies on demand and reports `Berhasil disalin`.

## Changes implemented in isolated preview
Repository: `Tutuk-project/paipai-pngtuber-v2-preview`

### Microphone
- Added `Mic ON / Mic OFF` toggle in the Home preview toolbar and Collaboration toolbar.
- Toggle updates state styling and pressed state.
- On successful login, app attempts to start microphone immediately; user/browser permission is still required. If permission or device access is denied, login remains usable and a visible error toast explains the issue.
- Toggle remains available to start/stop the microphone manually.

### Mobile UI
- Sidebar width reduced to 56–60 px on mobile.
- Navigation icons increased in size and centered.
- Expand/collapse control moved to a protruding vertical tab at the sidebar's mid-edge; labels switch between `›` and `‹`.
- Avatar preview viewport changed from an output-resolution-driven tall stage to a constrained viewport (mobile height approx. 220–300 CSS px; desktop cap 390 px). The actual output canvas resolution remains unchanged; only the on-screen preview viewport is contained.

### OBS link generator
- Added loading state with spinner animation.
- Generation now shows `Link berhasil dibuat` toast and changes all generator buttons to `Salin Link`.
- Copy action happens only when the user taps `Salin Link`, then shows `Berhasil disalin`.
- Copy helper uses Clipboard API on secure contexts and a textarea fallback.
- Removed native alert that exposed the full OBS URL and token in a large popup.
- Both Home and Collaboration generators share the same generated-link state while the current page remains open.

### Room reuse / ALREADY_IN_ROOM fix
- Added authenticated Edge Function action `get_my_active_room` to return the current user's non-expired active room membership.
- OBS generator looks up and reuses an active room before attempting `create_room`.
- If a create attempt still returns `ALREADY_IN_ROOM`, it retries lookup and uses that active room rather than failing immediately.
- Edge Function deployed to Supabase Development project `nbpqnwjxavuhpiuntcep`, function `vio-api`, version 9, ACTIVE, `verify_jwt=true`.
- Supabase Live was not modified.
