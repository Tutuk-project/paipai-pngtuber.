## Security review findings and changes
1. Direct Admin client RLS exceptions allowed cross-user profile, character, asset and Storage access without passing through audited Support View. Migration 002 replaces these policies with owner-only access. Admin cross-user inspection/mutation must use the service-role Edge Function routes and active support session where required.
2. Realtime read/write policies in migration 001 did not themselves require active, unexpired rooms for every branch. Migration 002 recreates both policies and checks room status and expiry for members and OBS overlay devices.
3. Admin bootstrap had a race window. Migration 002 serializes bootstrap with an advisory transaction lock and adds a unique partial index allowing only one Admin row.
4. Edge Function overlay_connect now checks expires_at before registering an OBS overlay device.
5. Disabling a user now ends active support-view sessions for that target.
6. Support detail now rejects targets that have since become disabled or Admin.
7. Non-host room leave now checks and surfaces database delete errors instead of ignoring them.
