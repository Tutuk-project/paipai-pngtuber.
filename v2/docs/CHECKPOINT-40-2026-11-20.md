# Checkpoint 40 — 20 November 2026

## New source inspection: Admin bootstrap contract

Inspected `v2/supabase/functions/vio-api/index.ts` on `develop/vio-studio-v2`.

The `bootstrap_admin` action contract is:
- HTTP method: POST to the Supabase Edge Function endpoint `/functions/v1/vio-api`.
- Request must carry a valid Supabase Auth access token for a freshly-created anonymous Auth session as `Authorization: Bearer <access_token>`.
- JSON body:
  ```json
  {
    "action": "bootstrap_admin",
    "username": "paipai77",
    "bootstrap_token": "<VIO_ADMIN_BOOTSTRAP_TOKEN>"
  }
  ```
- The function rejects non-anonymous sessions, any username other than `paipai77`, a missing configured secret, a supplied token shorter than 20 characters, or a token that does not exactly match `VIO_ADMIN_BOOTSTRAP_TOKEN`.
- On success it calls database RPC `vio_bootstrap_admin`, writes an audit event `bootstrap_admin`, and returns the created user.
- The success response explicitly instructs removing `VIO_ADMIN_BOOTSTRAP_TOKEN` from function secrets after first successful bootstrap.
