## Completed
1. Added renderer image-cache pruning after avatar assets, accessories and background images are refreshed.
2. Old signed-URL image objects are removed from the renderer cache when no longer referenced by the active avatar, accessories or background.
3. Event handlers are detached from discarded image objects to reduce retained references.
4. Effect sprite cache is capped at four configurations per image instead of twelve.
5. Added regression coverage proving stale signed URLs are pruned while current avatar, accessory and background sources remain cached.

## Why this matters
OBS and room snapshots refresh signed URLs periodically. Without pruning, every refreshed URL could create another retained Image object, while each image could retain several large effect canvases. This change bounds that accumulation during long-running streams.
