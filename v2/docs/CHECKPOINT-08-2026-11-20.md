## Background media integration completed
- Background mode selector supports transparent, solid, gradient, image/GIF, and video.
- Upload UI accepts PNG, JPEG, WebP, GIF, MP4, and WebM.
- Client limits: image/GIF 20 MB; video 50 MB.
- Background media is uploaded to a dedicated private Storage bucket, vio-backgrounds.
- Migration 004 creates/configures the private bucket, MIME allowlist, and owner-folder Storage policies.
- Edge Function record_background_asset validates owner-scoped path, MIME type, declared size, and confirms the uploaded object metadata before persisting it.
- Background metadata is stored in the user's profile preferences; signed URLs are generated server-side and are not persisted as long-lived profile data.
- `profile_get` now refreshes the signed background URL when the user returns in a later session.
- Storage MIME allowlist explicitly includes JPEG, matching the upload UI and Edge Function validator.
- my_assets returns a signed background URL for the editor.
- room_members and overlay_connect include signed background URLs for collaboration and OBS snapshots.
- profile_save strips transient signed URL values before persisting preferences.
- Renderer supports image/GIF drawing and a managed muted looping video element.
- Video source reuse avoids re-creating the media element on every microphone/render update; replacing or clearing a source pauses the previous video.
- Editor preview, room participant preview, and OBS overlay all pass saved background media into the shared renderer.
