## Completed in this checkpoint
1. Audited the canonical migrations 001–005 and added regression tests for accessory/background/cleanup schema dependencies and active-room Realtime authorization.
2. Hardened Admin account deletion:
   - disables the target account before deleting any linked Auth sessions;
   - ends active support sessions;
   - closes rooms hosted by the target and revokes room overlay tokens/devices;
   - removes non-host room memberships;
   - cancels queued Storage cleanup jobs when pre-deletion preparation or audit fails;
   - if Auth deletion partially fails, the remaining account stays disabled so remaining devices cannot continue using it.
3. Hardened the Storage cleanup worker:
   - checks expression and accessory metadata before removing an object from `vio-studio-assets`;
   - checks profile JSON references before removing an object from `vio-backgrounds`;
   - safely marks still-referenced objects as skipped rather than deleting them.
4. Added four regression tests for migration dependencies, Realtime active-room authorization, disable-before-Auth deletion, and reference-aware cleanup.
