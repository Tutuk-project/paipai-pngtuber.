## Legacy feature audit
The Online v1.0 reference contains seven effect types:
- Filter
- Stroke
- Shadow
- Emission / bloom
- Distortion
- Eagle eye
- Shake

The legacy effect engine also supports:
- Global effect engine enable/disable.
- A separate switch to allow effects on accessories.
- Per-effect intensity and color/shape parameters.
- Per-expression targeting: idle, talking, blink, talking + blink.
- Per-target targeting: avatar and accessories.
- Filter parameters: hue, saturation, brightness, contrast, invert, grayscale, sepia.

## Known parity gaps
- Eagle Eye currently uses a circular zoom lens; the legacy reference uses pixel-based fisheye remapping.
- Bloom currently uses a cached glow/blur pass; the legacy reference adds radial godray beams and dominant-color sampling.
- Stroke and shadow are functionally present but still need visual comparison against the original renderer at multiple output resolutions.
- No side-by-side visual regression test has been run on real browser canvases yet.
- Per-effect intensity and state/target selection are persisted through profile preferences; real multi-device propagation still needs live Realtime verification.
